# DroSens
Este repositorio se construye para albergar los datos generados más relevantes del proyecto DroSens, financiado por la Agencia Estatal de Investigación del Ministerio de Ciencia e Innovación y con código PID2020-116569RB-C3. El repositorio incluye el Plan de de Gestión de Datos (PGD) del proyecto, el cual sirve para describir dichos datos y señalar la forma de gestionarlos a partir de este momento. La organización del repositorio incluyen un conjunto de carpetas donde se encuentran los diferentes tipos de datos descritos en el PGD.
